# DIBURAMA — Notas de montaje final para Claude Code

## Objetivo
Construir una única experiencia continua. No debe parecer una suma de nueve vídeos generados por IA.

## Duraciones de referencia
01 1,8 s · 02 1,4 s · 03 1,8 s · 04 2,0 s · 05 2,0 s · 06 2,2 s · 07 2,0 s · 08 2,0 s · 09 4,0 s · cierre 2,5 s.

## Prioridad de montaje
1. Continuidad de dirección de cámara.
2. Match de forma entre final/inicio.
3. Igualar exposición y temperatura de color.
4. Ocultar pequeñas inconsistencias IA en motion blur / speed ramp / cut on action.
5. Nunca arreglar un mal clip con transiciones llamativas.

## Efectos permitidos
- Speed ramps moderadas.
- Optical flow únicamente si no deforma comida/manos.
- Motion blur direccional breve.
- Match dissolve de 2–4 frames cuando dos materiales comparten silueta.
- Light wrap / glow muy sutil en magenta Diburama.
- Film grain común a todo el master para unificar medios.

Plato vacío → 6–8 frames respiración → negro.
